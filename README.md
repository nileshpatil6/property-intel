# PropIntel — Unified UK Property Search + AI Intelligence

A working prototype for the **Property Search & Collection / AI Summaries / Reporting** tool.
One search interface that aggregates listings from **Zoopla, Rightmove and OnTheMarket**,
generates **AI summaries, value scores and comparisons**, and produces **exportable reports**.

Built by Nilesh Patil.

---

## This is real, not a mockup

- **OnTheMarket is scraped live** with Playwright. The 27 listings in the app were
  pulled from the real site — real prices, real photos, real agents and phone
  numbers, real addresses. Re-run `node scripts/scrape-live.mjs` to refresh them.
- **AI is real.** Every summary, value score and the market brief are generated by
  **OpenAI `gpt-5.4-mini`** (`scripts/generate-ai.mjs`), cached to
  `src/data/ai-cache.json`. The live `/api/summarize` route regenerates any
  listing on demand with the same model.

### Why only OnTheMarket is live in this build
Zoopla and Rightmove return **403 / Cloudflare "Just a moment"** to a datacentre
IP — verified during build. That is the real engineering challenge of this project.
The collectors for both are written (`src/lib/scrapers/zoopla.ts`,
`rightmove.ts`) and parse each site's real data structure (`__NEXT_DATA__` for
Zoopla, `jsonModel` for Rightmove). They run through a **residential-proxy
unlocker** (`proxyUnlocker.ts`) that rotates UK IPs and solves challenges — set
`PROXY_UNLOCKER_KEY` + `PROXY_UNLOCKER_ENDPOINT` and they go live with no other
change. I didn't put a paid proxy on a demo, but the path is built and ready.

## What it does (mapped to the brief)

**1) Property Search & Collection** — one search across 3 portals with source
badges; filters for buy/rent, beds, price, area/postcode/feature; live status dot
per source. Each listing: price, location, beds/baths, key features, agent detail,
full description, source link.

**2) AI-Powered Summaries** — real AI summary per listing, a **value score (0-100)**
benchmarked against the median for the same area + bedroom count + type, pros,
watch-outs, a one-line verdict. **Compare** 2-4 properties side by side with the AI
flagging the best on each metric. **AI Market Intelligence** panel: trends +
standout opportunities across the result set.

**3) Reporting** — clean web dashboard + "Export report" (print / save as PDF).
Email digests and downloadable CSV/PDF are straightforward extensions.

## Architecture

```
Browser  ->  Next.js dashboard
                |
                |- src/lib/scrapers/    collection layer
                |     OnTheMarket  -> Playwright (live, no proxy needed)
                |     Zoopla       -> __NEXT_DATA__ parser  } via residential-proxy
                |     Rightmove    -> jsonModel parser       } unlocker (Cloudflare)
                |     -> all normalised to one `Listing` shape
                |
                |- scripts/scrape-live.mjs  -> src/data/scraped.json  (real data)
                |
                |- gpt-5.4-mini    AI summaries, value scores, market insights
                      scripts/generate-ai.mjs builds the cache;
                      src/app/api/summarize regenerates live on demand
```

Adding a 4th portal = one new file that returns the same `Listing` shape.

## Run it

```bash
cp .env.local.example .env.local   # add OPENAI_API_KEY
npm install
npm run dev          # http://localhost:3000
```

Refresh the real data / AI:
```bash
node scripts/scrape-live.mjs                          # re-scrape OnTheMarket live
node scripts/generate-ai.mjs                          # regenerate AI on the new data
```

Enable Zoopla + Rightmove live: set `PROXY_UNLOCKER_KEY` and
`PROXY_UNLOCKER_ENDPOINT` in `.env.local`.
